# Epic 15 — Lab Notes (Editorial Changelog)

## Goal
Add a public `lab notes` page that documents shipped changes in a tone that matches the product: dry, self-incriminating, and lightly judgmental.

## Why this Epic Exists
The product has a strong voice everywhere else, but no place to record what changed. A normal changelog would feel too corporate. `lab notes` gives the app an editorial release log that feels native to the project while still grounding entries in real commits.

## Scope
- Static `/lab-notes` route rendered from curated local data
- Date-grouped release log with reverse-chronological entries
- Commit-backed metadata for each note, including multi-commit entries
- Optional inline media blocks for release-backed notes
- Secondary version chips for notes that ship a named release artifact
- Footer navigation entry for `lab notes`
- Visual treatment aligned with the existing monochrome-luxe UI system
- Compact `generated by ai` badge on commit-backed entries

## Out of Scope
- Automatic changelog generation from git history
- Markdown/CMS authoring workflow
- Search, filtering, or tag archives
- RSS, release feeds, or notifications

## Technical Notes

### Data model
Entries are intentionally curated rather than derived. The source of truth lives in `src/data/lab-notes.ts`:

```ts
type LabNoteEntry = {
  date: string
  title: string
  note?: string
  tag: 'feature' | 'fix' | 'experiment' | 'adjustment'
  version?: string
  commitHashes?: string[]
  media?: LabNoteMedia[]
}
```

### Rendering approach
The page avoids a decorative timeline treatment. It uses the same card language as the rest of the site:
- narrow centered layout
- mono metadata row
- restrained borders and hover lifts
- optional inline media frame for entries with release assets
- no extra visual gimmicks beyond existing `animate-rise`

### Tone guardrails
The page should read like a release ledger, not a tweet thread:
- dry over loud
- observational over punchline-heavy
- self-aware, but not trying to perform
- funny because the wording is controlled
