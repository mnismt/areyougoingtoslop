# Calibration Dataset

This folder holds lightweight reference profiles used to sanity-check the
scoring model before launch. The goal is to avoid obvious false positives and
keep the roast fun and grounded.

## How to use
- Compare new model weights against the sample expectations.
- Focus on directionally correct tiers rather than exact scores.
- Update notes as the product tone evolves.

## Files
- `calibration-samples.json`: Small set of archetypal contribution profiles.
